# SUSFS manager port

The SUSFS userspace API, persistent configuration model, and manager screens in
this repository are adapted from the GPL-3.0-only ReSukiSU implementation,
primarily ReSukiSU commit `97163bdc8ad2ee59b523e9e34edeb4c286eceb04` and its
follow-up fixes.

Upstream: https://github.com/ReSukiSU/ReSukiSU

KowSU-specific changes keep the existing KowSU application identity, dual UI
mode, Navigation 3 stack, bundled `ksud`, and production signing workflow.
